# Loop Engineering

Enter only after explicit `loop` invocation or user approval. State role, bounded scope, maximum attempts from project settings, exit condition, verification method, allowed side effects, and escalation condition.

Each iteration is `observe -> dispatch specialist -> verify evidence -> record -> stop, retry, or escalate`. A loop cannot expand its role authority. Stop for approval, ambiguity, repeated failure, timeout, budget exhaustion, conflicting evidence, destructive/external action, or a missing prerequisite.
