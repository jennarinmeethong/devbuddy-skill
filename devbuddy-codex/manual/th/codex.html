Codex workflow

ใช้ $devbuddy <role> <task> สำหรับ graph ที่มี specialist เดียว หรือ $devbuddy owner <task> สำหรับ orchestration หลาย role การใช้ loop ต้องระบุ loop อย่างชัดเจน

Codex ต้องมีการเรียก subagent ที่รับค่า model และ effort ได้ หากไม่มี DevBuddy จะ block และถาม user โดย Orchestrator จะไม่ทำงานแทน specialist

Memory

ใช้ python scripts/init_project_memory.py --root <approved-memory-root> --dry-run ก่อนสร้าง project memory ที่หายไป command จะไม่เขียนทับ core files เดิม

ตรวจสอบ

python scripts/validate_skill_metadata.py .; python scripts/validate_project_settings.py <project-root>/.devbuddy/settings.yaml; python scripts/validate_knowledge.py <memory-root>; python scripts/check_adapter_conformance.py; python scripts/run_scenarios.py tests/scenarios.json
