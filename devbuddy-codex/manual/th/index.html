DevBuddy Codex adapter

เรียกใช้แบบชัดเจนด้วย $devbuddy โดย Orchestrator ดูแลสถานะ การอนุมัติ lock การเลือก model/effort และการส่งต่องาน ส่วน role เฉพาะทางเป็นผู้ทำงาน

ติดตั้ง

  1. คัดลอก folder devbuddy-codex ที่เสร็จแล้วไปยัง Codex skills directory ที่อนุมัติ
  2. ตรวจว่า Codex อ่าน SKILL.md และ agents/openai.yaml ได้
  3. สร้างและตรวจ <project-root>/.devbuddy/settings.yaml ก่อน dispatch
  4. เรียก $devbuddy owner <task>

ความปลอดภัยในการ dispatch

ทุกครั้งที่เรียก subagent ต้องส่ง model และ effort level ที่อนุมัติแบบ explicit ระบบเลือกคู่ที่ rank ต่ำสุดซึ่งเพียงพอกับ role และ risk หากไม่มี allowlist budget การอนุมัติ หรือ subagent capability task จะเป็น waiting_user
