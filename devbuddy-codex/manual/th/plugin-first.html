Codex · Plugin-first

ติดตั้ง DevBuddy ผ่าน Plugin/profile

การติดตั้งใหม่ใช้ Codex Plugin และ profile ที่เลือก; portable core ถูก bundle มาแล้ว ไม่ต้องติดตั้งแยก

ติดตั้งและเรียกใช้

# ใน Codex Plugin manager ติดตั้ง plugin/devbuddy-codex
python scripts/profile_resolver.py profiles/codex.yaml --platform codex
# refresh Codex
$devbuddy <task>

เลือก optional capability ผ่าน profile เท่านั้น resolver จะ preview package composition ก่อนและต้องระบุ --apply ก่อนบันทึก workspace state

Migration และ rollback

python3 devbuddy-codex/scripts/install_codex_adapter.py --migration-report
# เฉพาะ legacy compatibility
python3 devbuddy-codex/scripts/install_codex_adapter.py --legacy-install --apply

Migration report เป็น read-only การ disable/remove Plugin/profile คือ rollback path; shim คง legacy skill ไว้และปฏิเสธ unknown-file conflict
