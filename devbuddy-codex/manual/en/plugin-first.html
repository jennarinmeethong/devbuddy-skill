Codex · Plugin-first

Install DevBuddy through a Plugin/profile

New installations use the DevBuddy Codex Plugin and a selected profile; the portable core is bundled rather than installed independently.

Install and invoke

# In the Codex Plugin manager, install plugin/devbuddy-codex
python scripts/profile_resolver.py profiles/codex.yaml --platform codex
# refresh Codex
$devbuddy <task>

Choose optional capabilities only through a profile. The resolver previews the package composition first and requires --apply before recording workspace state.

Migration and rollback

python3 devbuddy-codex/scripts/install_codex_adapter.py --migration-report
# Legacy compatibility only
python3 devbuddy-codex/scripts/install_codex_adapter.py --legacy-install --apply

The migration report is read-only. Plugin/profile removal or disablement is the rollback path; the shim retains the legacy skill and refuses unknown-file conflicts.
