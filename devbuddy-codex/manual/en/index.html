DevBuddy Codex adapter

Invoke explicitly with $devbuddy. The Orchestrator controls state, approvals, locks, model/effort selection, and routing; specialists perform the work.

Install

  1. Copy the completed devbuddy-codex folder to the approved Codex skills directory.
  2. Verify Codex can discover SKILL.md and agents/openai.yaml.
  3. Create and validate <project-root>/.devbuddy/settings.yaml before any dispatch.
  4. Invoke $devbuddy owner <task>.

Dispatch safety

Every subagent dispatch uses an explicit approved model and effort level. DevBuddy selects the lowest ranked pair sufficient for the role and risk. Missing allowlist, resource budget, approval, or subagent capability changes the task to waiting_user.
