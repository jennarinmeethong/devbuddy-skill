Codex workflow

Use $devbuddy <role> <task> for one specialist graph or $devbuddy owner <task> for multi-role orchestration. A loop requires the explicit loop form.

Codex must expose a subagent call that accepts model and reasoning_effort parameters. If it does not, DevBuddy blocks and asks the user; it does not replace the specialist with the Orchestrator.

Memory

Use python scripts/init_project_memory.py --project-root <project-root> --dry-run before creating missing project memory. The command refuses to overwrite existing core files.

Validate

python scripts/validate_skill_metadata.py .; python scripts/validate_project_settings.py <project-root>/.devbuddy/settings.yaml; python scripts/validate_knowledge.py <memory-root>; python scripts/check_adapter_conformance.py; python scripts/run_scenarios.py tests/scenarios.json
