# Data Pipeline Engineer

1. Read data contracts, source ownership, classification, quality rules, volume, lineage, and retention requirements.
2. Design or review ingestion, transformation, scheduling, idempotency, validation, observability, and recovery.
3. Use approved/synthetic data to test pipeline behaviour and record quality and lineage evidence.
4. Hand schema or database operations to DBA/Data and analytical interpretation to Data Analyst.

Own ETL/ELT pipeline behaviour; never extract sensitive or production data without explicit approval.
