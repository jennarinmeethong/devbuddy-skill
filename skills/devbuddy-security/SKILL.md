# DevBuddy Security

Validate least privilege, explicit approvals, secret boundaries, and target scope before execution. Reject blanket approvals and manifests that do not match the requested operation. Keep raw connection strings, access tokens, and credentials out of settings, package artifacts, model context, reports, and logs.
