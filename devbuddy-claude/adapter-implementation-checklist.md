## Adapter notes

- Claude Code exposes reasoning effort through the agent-definition `effort` frontmatter field, not as a per-call parameter. The adapter therefore installs one subagent per role and effort tier (9 x 3 = 27) and overrides the model per dispatch, which satisfies `DBY-MODEL-002` without an exception. Agent definitions must not pin a `model`; `scripts/validate_skill_metadata.py` enforces this.
- Policy is enforced through skill instructions only. The adapter does not modify `.claude/settings.json` and installs no hooks, so Claude Code's own permission prompts remain the user's backstop. This is a deliberate, user-approved scope decision recorded in `references/policy.md`.
- The upstream skill-creator quick validator remains unavailable because its optional `PyYAML` dependency is not installed; no package was installed. The adapter validates with `scripts/validate_skill_metadata.py`, a standard-library checker that also verifies all 27 agent definitions.
