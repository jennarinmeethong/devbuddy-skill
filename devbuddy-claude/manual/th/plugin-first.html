Claude Code · Plugin-first

ติดตั้ง DevBuddy ผ่าน Plugin

การติดตั้งใหม่ใช้ Plugin/profile เดียว; ไม่ต้องติดตั้ง core skill หรือ Claude adapter แยกต่างหาก

ติดตั้งและเรียกใช้

claude plugin marketplace add <DevBuddy marketplace repository or local path>
claude plugin install devbuddy-claude-code@devbuddy --scope user
# ใน Claude Code
/reload-plugins
/devbuddy-claude-code:devbuddy <task>

Claude Code จะ namespace skill ของ Plugin จึงใช้คำสั่ง /devbuddy-claude-code:devbuddy สำหรับ Plugin ใหม่ ไม่ใช่ /devbuddy แบบ standalone เดิม

ตรวจสอบ อัปเดต และ rollback

claude plugin list --json
claude plugin update devbuddy-claude-code@devbuddy
claude plugin uninstall devbuddy-claude-code@devbuddy --keep-data

Installer เดิมเป็น compatibility shim ตลอด DevBuddy 1.x: จะ preview migration ก่อนเสมอ, ต้องระบุ --legacy-install จึงจะคัดลอกไฟล์, ไม่เขียนทับไฟล์ที่ไม่รู้จัก และไม่ลบ installation เดิม
