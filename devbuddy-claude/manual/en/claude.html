Adapter guide

Claude Code adapter

Install `/devbuddy`, configure role/effort agents, and keep runtime memory commands project-local.

Manual 0.4.4Claude Code

Install and refresh

Claude installer 
python3 devbuddy-claude/scripts/install_claude_adapter.py
python3 devbuddy-claude/scripts/install_claude_adapter.py --apply

Use --claude-root for a non-default configuration root. Refresh the Claude Code session after applying.

Invoke DevBuddy

Invocation 
/devbuddy <task>
/devbuddy analyze <project-id>

The adapter routes the request to the orchestrator. Use the shared pages for workspace, scripts, tasks and migration commands.

Platform contract

  • Gate entry with disable-model-invocation: true so only an explicit /devbuddy opens the workflow.
  • Carry effort through the selected devbuddy-<role>-<effort> agent definition.
  • Carry the approved model through the per-call Agent tool parameter.
  • Use only settings entries tagged for Claude; switching adapters never changes the workspace setting.
  • Keep specialists away from direct `.devbuddy/` writes.
  • Require structured JSON slice records and evidence before closure.
