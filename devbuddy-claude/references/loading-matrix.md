# Reference Loading Matrix

Read the named reference before the corresponding action; do not preload unrelated references.

| Situation | Read |
|---|---|
| Any delivery task | `policy.md`, adapter dispatch contract |
| Select roles or process a role override | `role-routing.md`, `roles/<role>.md` |
| Select model, effort, timeout, retry, or adapter profile | `settings.md`, adapter dispatch contract |
| Create, resume, record, lock, commit, or analyse a task | `task-memory.md`, `knowledge-model.md` |
| Find which knowledge key covers a topic | `Index.md`, before opening any typed entity |
| Propose or write canonical knowledge | `knowledge-model.md`, relevant typed entity and impact evidence |
| Enter or continue a loop | `loop.md` |
| Propose, register, or invoke a custom tool | `custom-tools.md` |
| Change source specification, adapters, checklists, or manuals | source `policies.md`, `adapter-contract.md`, `scripts.md` |
