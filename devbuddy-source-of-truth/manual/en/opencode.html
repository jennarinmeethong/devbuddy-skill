Host guide

Use DevBuddy with OpenCode

Install the adapter once, then materialize only the agent preset each project needs.

Before installing

You need a working OpenCode installation, Terminal, and an approved release tag or full commit SHA from an administrator. Replace <approved-ref> below; do not use a mutable branch for real work.

Install the adapter

OpenCode 
opencode plugin 'github:jennarinmeethong/devbuddy-skill#<approved-ref>::path:plugin/devbuddy-core/opencode' --global

Keep --global to use it in every local project, or remove it for the current project only. ::path: installs the OpenCode adapter rather than the entire repository.

Create agent presets for a project

Choose a preset from the Profile guide, then use the installed OpenCode adapter folder as <plugin-directory>. The first command does not write files. Review its list, then add --apply.

Preview, then apply 
python3 <plugin-directory>/scripts/materialize_agents.py \
  --preset product-delivery --project-root <project>

python3 <plugin-directory>/scripts/materialize_agents.py \
  --preset product-delivery --project-root <project> --apply

Agent files live under .opencode/agents/devbuddy/ and have IDs like devbuddy/<role>. The materializer stops rather than overwriting an existing agent definition.

How to choose a preset

PresetBest for
product-deliveryBuilding or changing a product.
cloud-operationsCloud, CI/CD, and reliability.
data-aiData pipelines, analysis, and AI evaluation.
support-knowledgeSupport, FAQs, and guides.

A Profile is role-selection metadata, not a permission grant. Read the detailed add and remove process in Profiles.

Use it safely

Begin with a prompt that asks for a plan, review the scope and roles, then approve file changes or external actions. Never put secrets in an agent file or prompt. Database and production work always need target-specific approval.

When something goes wrong

If the plugin is missing, check the ref and command syntax. If materialization reports an existing file, do not overwrite it; inspect the agent or choose another preset. Open Troubleshooting for general errors.
