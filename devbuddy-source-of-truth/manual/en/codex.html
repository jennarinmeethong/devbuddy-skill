Adapter guide

Codex adapter

Install `$devbuddy`, configure explicit model and effort transport, and keep runtime memory commands project-local.

Manual 0.4.4Codex

Install and refresh

Codex installer 
python3 devbuddy-codex/scripts/install_codex_adapter.py
python3 devbuddy-codex/scripts/install_codex_adapter.py --apply

Use --codex-root for a non-default configuration root. Refresh the Codex session after applying.

Invoke DevBuddy

Invocation 
$devbuddy <task>
$devbuddy analyze <project-id>

The adapter routes the request to the orchestrator. Use the shared pages for workspace, scripts, tasks and migration commands.

Platform contract

  • Pass an explicit approved model and reasoning_effort for each specialist dispatch.
  • Use only settings entries tagged for Codex; switching adapters never changes the workspace setting.
  • Block dispatch when the subagent mechanism cannot accept both values.
  • Keep specialists away from direct `.devbuddy/` writes.
  • Require structured JSON slice records and evidence before closure.
