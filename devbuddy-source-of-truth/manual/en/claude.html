Claude Code Skill adapter

Status: not implemented at version 0.1.0. Do not treat this page as an instruction to install an unavailable adapter.

Prerequisites

  • Claude Code installed, authenticated, and supported in the target environment.
  • Node.js and network/account prerequisites required by the current Claude Code installation guide.
  • Explicit user approval for any installation, update, paid account, or model usage.
  • Python available if the adapter exposes the common validation scripts.

Verify the actual installation with claude doctor only after the user authorises running it. Official setup guidance: Anthropic Claude Code setup.

Installation when the checklist is complete

  1. Confirm every required item in devbuddy-claude/adapter-implementation-checklist.md is done.
  2. Read the adapter's own SKILL.md for its verified install location and permission mapping.
  3. Copy only the completed adapter into the user-approved Claude Code Skill location.
  4. Open a project, invoke the Skill, and run its documented read-only health check.
  5. Verify the adapter checklist, settings mapping, memory resolution, and manual conformance.

Never copy credentials, connection strings, or personal data into Claude settings or prompts.

Adapter behaviour

The Claude adapter must preserve common policy: Thai user communication, English internal handoffs, no guessing, Git read-only default, user approval for cost/tool/install/external actions, knowledge impact approval, and adapter checklist evidence.

Troubleshooting

  • If Claude Code is unavailable, ask the user whether to install it or use another approved platform.
  • If permissions, tool access, or model availability differ from the common policy, mark the checklist item incomplete and record a remark.
  • Do not use a permission-bypass mode to work around DevBuddy approvals.
