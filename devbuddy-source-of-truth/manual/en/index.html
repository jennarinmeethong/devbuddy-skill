A beginner-friendly guide

Start with DevBuddy, even if AI is new to you

DevBuddy turns an outcome you describe into a work plan, routes parts to specialist AI agents, and reports back verified evidence. You can state your goal in ordinary language; you do not need to know commands or write code first.

Manual 0.4.6Codex · Claude Code · OpenCodeStart safely

What DevBuddy does—and does not do

Think of DevBuddy as a team coordinator, not a button that changes everything immediately. It clarifies the request, plans the work, selects specialists such as requirements analysts, developers, testers, and security reviewers, and returns evidence.

You remain the decision-maker. DevBuddy must ask before a cost, a write or destructive action, an external data transfer, production access, or sensitive-data handling. Start with a small task and ask to review the plan first.

Your 20-minute first path

  1. Choose one host: Codex, Claude Code, or OpenCode—the one you already use.
  2. Install its plugin from choose and install a host, or ask a project administrator to install it.
  3. Start your first request by describing the goal, what already exists, constraints, and the outcome you want.
  4. Read the plan first, then confirm scope and risk before allowing file edits, commands, or external services.
  5. Use a workspace when ready for work lasting more than one session or spanning repositories.

The step-by-step guide contains copyable commands and example prompts for all three hosts.

Useful terms in plain language

TermMeaning
AI agentAn AI helper assigned to one kind of work, such as requirements analysis or testing.
HostThe app where you work with AI: Codex, Claude Code, or OpenCode.
PluginA package of instructions and roles that adds DevBuddy to a host.
Profile / presetA useful set of roles for a type of work. It does not grant permissions by itself.
Dry runA preview of what would happen; it does not write or change files.
WorkspaceThe .devbuddy folder that stores project task state and knowledge.

Choose the right path

If you want to…Start here
Ask AI to plan a small piece of workInstall your host plugin, then use the example prompt in Get started.
Build or change a web site or applicationUse the product-delivery preset.
Operate deployment, cloud, or an incidentUse the cloud-operations preset.
Analyse data or evaluate an AI modelUse the data-ai preset.
Write help content or support usersUse the support-knowledge preset.

You do not need to pick a role for your first task. Give DevBuddy the goal and let it propose a suitable team first. Role overrides are for advanced users who intentionally want to constrain routing.

Four simple safety rules

  • Never paste passwords, API keys, payment data, or customer data into a prompt or manual.
  • Do not approve a command you do not understand. Ask for a plain-language explanation and a dry run first.
  • Use a copy of the repository or a test branch for your first trial.
  • For databases and production, use the least privilege possible and approve a specific action each time.

Where to go next

Begin with the step-by-step guide. If DevBuddy is installed but does not appear, open Troubleshooting. Once your first prompt succeeds, read Workspace to keep shared history for real project work.
