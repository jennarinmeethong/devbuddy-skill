Start safely

DevBuddy routes work to specialist roles. It never silently replaces the owner, bypasses approvals or writes canonical knowledge from an unreviewed scan.

Recommended pathBegin with Getting started, then read Workspace when FE and BE repositories share one knowledge base.

Documentation path

  1. Getting started — install, initialize, configure and validate.
  2. Workspace — choose `.devbuddy`, register projects and organize knowledge.
  3. Scripts — understand every Python tool and its write boundary.
  4. Tasks & knowledge — coordinate tasks and owner-controlled knowledge.
  5. Migration — move old layouts and upgrade tools safely.
  6. Troubleshooting — resolve common setup and runtime errors.

Design principles

  • Runtime Python lives in the project workspace after bootstrap.
  • Knowledge is explicit, evidence-backed and scoped to project IDs.
  • Dry-run, approval and validation gates appear before writes.
  • The manual works from `file://` or a static HTTP server without a build step.
