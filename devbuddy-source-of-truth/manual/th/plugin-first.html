Claude Code · Plugin-first

ติดตั้ง DevBuddy ผ่าน Plugin marketplace

การติดตั้ง Claude Code ใหม่ใช้ marketplace Plugin เดียว โดย Plugin จะ bundle core dependency และ role/effort agents ให้พร้อมใช้

เพิ่ม marketplace ติดตั้ง และ refresh

claude plugin validate plugin/devbuddy-claude-code; claude plugin marketplace add ./; claude plugin install devbuddy-claude-code@devbuddy --scope user --yes; claude plugin list --json; /reload-plugins; /devbuddy-claude-code:devbuddy <task>

ที่ root ของ repository มี .claude-plugin/marketplace.json และ Claude Code จะ namespace skill ของ Plugin ดังนั้น entrypoint ของ Plugin คือ /devbuddy-claude-code:devbuddy; ส่วน /devbuddy แบบไม่มี namespace ใช้เฉพาะ legacy standalone compatibility shim

อัปเดต ตรวจสอบ และ rollback

claude plugin marketplace update devbuddy; claude plugin update devbuddy-claude-code@devbuddy; claude plugin list --json; claude plugin uninstall devbuddy-claude-code@devbuddy --keep-data

หลัง update ให้ใช้ /reload-plugins และตรวจ entrypoint แบบมี namespace หากต้อง rollback ให้ uninstall ด้วย --keep-data แล้ว restore version ที่อนุมัติจาก marketplace จากนั้นติดตั้งและ refresh ใหม่ ส่วน installer เดิมยังเป็น compatibility path แบบ dry-run-first ตลอด DevBuddy 1.x

ความปลอดภัยและ ownership

  • validate manifest ก่อนติดตั้ง และใช้ --yes หลังตรวจ source แล้วเท่านั้น
  • Plugin ขึ้นกับ devbuddy-core ไม่ต้องติดตั้ง core skill แยกอีกชุด
  • Plugin เป็นเจ้าของ host payload ส่วน project state, secret, task ledger และ knowledge อยู่นอก package artifact
  • ใช้ standalone installer เฉพาะ migration report หรือ legacy compatibility install ที่อนุมัติแล้ว
