Workspace

รวม knowledge, task coordination และ project-local tools ไว้ด้วยกัน ขณะที่ source code อยู่ใน repository ของตัวเอง

Manual 0.4.6Multi-projectUser-owned state

เลือก workspace root

.devbuddy เป็น control directory จึงไม่จำเป็นต้องอยู่ใน application repository เดียว วางไว้ข้าง FE/BE หรือใน knowledge Git repository แยกได้ Plugin ของ host เป็นเจ้าของ initializer และ delivery payload ส่วน workspace เป็นเจ้าของ generated state

workspace/
├── frontend/
├── backend/
└── knowledge-repo/
    └── .devbuddy/
        ├── settings.yaml
        ├── knowledge-base/
        ├── tasks/
        └── tools/

ลงทะเบียนหลาย project

Project ID เป็นชื่อคงที่ที่ settings, bootstrap, knowledge metadata และ task scope ใช้ร่วมกัน path จะ resolve จาก parent ของ .devbuddy

settings.yaml 
workspace:
  projects:
    fe:
      path: ../frontend
    be:
      path: ../backend
memory_root: knowledge-base

initializer จะ reject path ที่ไม่มีอยู่, ID ซ้ำ, path ซ้ำหลัง resolve หรือ path ที่อยู่ภายใน .devbuddy

แต่ละ path ใช้ทำอะไร

Pathหน้าที่
.devbuddy/knowledge-base/Shared canonical knowledge และ bootstrap observation ที่ review ได้
.devbuddy/tasks/workspace ledger, slice record, reservation และ analysis
.devbuddy/tools/Python runtime ที่ package initializer copy พร้อม manifest hash
.devbuddy/settings.yamlproject registry และ orchestration policy
Source repositoriesFE, BE หรือ source อื่น; specialist เขียนเฉพาะ scope ที่อนุมัติ

Dedicated knowledge repository

commit .devbuddy/ ใน knowledge repository และใช้ relative source path เพื่อให้ clone แล้วย้ายเครื่องได้สะดวก ถ้าต้องใช้ absolute path ให้เก็บเป็น local override นอก settings ที่ commit

เหตุผลด้าน antivirusหลัง bootstrap Python operational จะรันจาก workspace ที่ scanner รู้จัก ส่วน Plugin ให้ initializer และ template สำหรับครั้งแรก ไม่แทนการ validate runtime ใน project

การตั้งชื่อ shared knowledge

core files และ typed folders อยู่ใต้ knowledge-base/ ทุก entity ต้องมี immutable ID และ project_ids ที่ไม่ว่าง fact ร่วมอาจระบุทั้ง fe และ be ส่วน evidence เฉพาะ repository ต้องระบุ project ID และ relative source path
