Codex Skill adapter

สถานะ: ยังไม่ได้ implement ใน version 0.1.0 source-of-truth กำหนด target แล้ว แต่ Codex adapter ยังไม่ผ่าน checklist

Target format

adapter ที่เสร็จต้องใช้ Codex Skill structure มาตรฐานปัจจุบัน: folder ที่มี SKILL.md และ agents/openai.yaml และอาจมี references, templates, scripts หรือ assets ที่จำเป็นต่อ platform adaptation

วิธีติดตั้งเมื่อ checklist เสร็จ

  1. ตรวจว่าทุกรายการที่ต้องทำใน devbuddy-codex/adapter-implementation-checklist.md เป็น done
  2. อ่าน SKILL.md ของ adapter ที่เสร็จและตรวจ compatibility กับ Codex ปัจจุบัน
  3. copy adapter folder ไปยัง Codex skills location ที่ user อนุมัติ โดยทั่วไปคือ $CODEX_HOME/skills หรือ ~/.codex/skills ตาม installation ที่ใช้งาน
  4. restart/refresh Codex หาก installation นั้นต้องการ แล้ว invoke Skill ตาม prompt ในคู่มือ
  5. รัน validation แบบ read-only และตรวจ settings, memory location, tool availability และ adapter/manual conformance

ห้ามติดตั้ง plugin, runtime หรือ dependency เพื่อทำขั้นตอนเหล่านี้เอง ต้องถาม user ก่อน

Configuration

project override เก็บใน <project-root>/.devbuddy/settings.yaml ไฟล์นี้ชี้ไปยัง external memory root เช่น Obsidian vault ได้ แต่ห้ามมี knowledge content, secret หรือข้อมูลส่วนบุคคล คำสั่งตรงของ user มาก่อน project settings แล้วจึง common settings

แก้ปัญหา

  • หาก Codex หา adapter ไม่พบ ให้ตรวจตำแหน่ง SKILL.md frontmatter และ agents/openai.yaml
  • หาก platform capability ทำตาม policy กลางไม่ได้ ให้คง checklist item ว่ายังไม่เสร็จและบันทึก limitation
  • ห้ามข้าม Git, cost, tool, approval, privacy หรือ endpoint policy เพื่อให้ adapter ดูเหมือนเสร็จ
