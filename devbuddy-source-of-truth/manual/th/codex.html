Codex Skill adapter

สถานะ: implement แล้วตาม common specification 0.1.1 แต่ต้องตรวจใน Codex environment เป้าหมายก่อนใช้งาน

รูปแบบเป้าหมาย

adapter ใช้ Codex Skill structure ปัจจุบัน: SKILL.md, agents/openai.yaml, role profiles, settings/schema, templates, standard-library validation scripts, scenarios และคู่มือสองภาษาในตัว

ติดตั้งและตั้งค่า

  1. คัดลอก folder devbuddy-codex ที่เสร็จแล้วไปยัง Codex skills location ที่ user อนุมัติ
  2. ตรวจว่า Codex ค้นพบ SKILL.md และ agents/openai.yaml
  3. สร้าง <project-root>/.devbuddy/settings.yaml ที่มี ranked model/effort allowlist, concurrency, timeout และ retry ที่อนุมัติ
  4. รัน validation แบบ read-only ตามคู่มือ
  5. เรียก $devbuddy owner <task>

พฤติกรรม Codex dispatch

Orchestrator เลือก model ที่ความสามารถต่ำสุดและ effort ต่ำสุดที่อนุมัติซึ่งเพียงพอกับ specialist slice ทุกงาน บันทึกเหตุผล และส่งทั้งสองค่าไปกับ Codex subagent call หาก settings, approval, resource budget หรือ subagent capability ขาด task จะเป็น waiting_user; Orchestrator จะไม่ทำงานแทน specialist

แก้ปัญหา

  • หาก Codex สร้าง subagent พร้อมค่า model และ effort ไม่ได้ ห้ามใช้ workflow ทดแทน ให้ถาม user เพื่อเปิด capability หรือเลือก platform อื่น
  • หาก project settings ไม่มีหรือไม่ผ่าน ให้ตรวจ settings ก่อน dispatch
  • ห้ามข้าม Git, cost, tool, approval, privacy หรือ endpoint policy เพื่อให้ adapter ดูเหมือนใช้งานได้
