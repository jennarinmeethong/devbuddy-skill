Installer แจ้ง collision

เลือก config root ใหม่หรือ inspect ไฟล์เป้าหมาย installer จะ replace เฉพาะ DevBuddy artifact ที่รู้จักและไม่ทับไฟล์อื่น

Initializer reject project

ตรวจว่า path มีอยู่, ไม่ซ้ำหลัง resolve และอยู่นอก `.devbuddy` Relative path resolve จาก parent ของ workspace root

Settings validation fail

ตรวจ `memory_root: knowledge-base`, project อย่างน้อยหนึ่งรายการ, paths ที่มีอยู่, ranks ที่ไม่ซ้ำ, budgets และ roles/risks ที่อนุญาต

ตรวจ settings 
python3 .devbuddy/tools/validate_project_settings.py .devbuddy/settings.yaml

Upgrade tool ถูก block

ไฟล์ปัจจุบันต่างจาก manifest hash ให้ review diff แล้ว restore trusted version หรือจัดการ change เอง ห้าม force replace unknown file

Bootstrap apply ไม่ผ่าน

อาจมี observation ของ project นี้แล้วหรือ knowledge file ไม่ใช่ scaffoldable ให้ review section เดิมและ promote ผ่าน owner protocol

Antivirus เตือน runtime

ตรวจว่าคำสั่ง runtime ใช้ `.devbuddy/tools/` และ installed skill รัน initializer เฉพาะตอน bootstrap อย่าปิด scanner หรือ bypass quarantine

หลักฐานเก็บ warning และ path ที่รันไว้ใน task evidence เพื่อให้ตรวจสอบได้

Checklist ตรวจสอบ

  • Validate settings
  • Validate knowledge
  • Validate task ledger
  • Review manifest hashes
  • ตรวจ project-qualified scopes
  • บันทึก evidence ใน ledger
