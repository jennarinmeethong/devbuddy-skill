คู่มือสำหรับผู้เริ่มต้น

เริ่มใช้ DevBuddy แม้ยังไม่รู้จัก AI

DevBuddy ช่วยเปลี่ยนสิ่งที่คุณอยากทำให้เป็นแผนงาน แบ่งงานให้ผู้เชี่ยวชาญ AI และสรุปสิ่งที่ตรวจสอบแล้ว คุณบอกเป้าหมายเป็นภาษาปกติได้ ไม่จำเป็นต้องรู้คำสั่งหรือเขียนโค้ดก่อน

Manual 0.4.6Codex · Claude Code · OpenCodeเริ่มแบบปลอดภัย

สิ่งที่ DevBuddy ทำให้ และสิ่งที่ไม่ทำ

คิดว่า DevBuddy เป็นผู้ประสานงานทีม ไม่ใช่ปุ่มที่สั่งให้ระบบเปลี่ยนทุกอย่างทันที มันช่วยถามให้ชัด วางแผน เลือกผู้เชี่ยวชาญ เช่น นักวิเคราะห์ความต้องการ นักพัฒนา ผู้ทดสอบ หรือผู้ตรวจความปลอดภัย แล้วรายงานหลักฐานกลับมา

คุณยังเป็นผู้ตัดสินใจDevBuddy ต้องขออนุมัติก่อนทำสิ่งที่มีค่าใช้จ่าย เขียนหรือทำลายข้อมูล ส่งข้อมูลออกนอกเครื่อง แตะ production หรือใช้ข้อมูลละเอียดอ่อน เริ่มจากงานเล็กและให้ตรวจแผนก่อนเสมอ

เส้นทางเริ่มต้น 20 นาที

  1. เลือก host เพียงหนึ่งตัว คือ Codex, Claude Code หรือ OpenCode ที่คุณใช้อยู่แล้ว
  2. ติดตั้ง plugin ตามหน้า เลือกและติดตั้ง host หรือขอผู้ดูแลโครงการช่วยติดตั้ง
  3. เริ่มคำขอแรก บอกเป้าหมาย สิ่งที่มีอยู่ ข้อจำกัด และสิ่งที่อยากได้กลับมา
  4. อ่านแผนก่อน ยืนยันขอบเขตและความเสี่ยงก่อนอนุญาตให้แก้ไฟล์ รันคำสั่ง หรือใช้บริการภายนอก
  5. ใช้ workspace เมื่อพร้อม หากทำงานหลายวันหรือหลาย repository ให้สร้างพื้นที่เก็บ task และความรู้ร่วมกัน

หน้า เริ่มต้นใช้งานทีละขั้น มีคำสั่งคัดลอกและตัวอย่าง prompt ครบทั้งสาม host

คำศัพท์สั้น ๆ ที่ควรรู้

คำหมายความว่า
AI agentผู้ช่วย AI ที่รับผิดชอบงานหนึ่งแบบ เช่น วิเคราะห์ requirement หรือทดสอบ
Hostแอปที่คุณใช้คุยกับ AI: Codex, Claude Code หรือ OpenCode
Pluginชุดคำสั่งและบทบาทที่เพิ่มความสามารถ DevBuddy เข้าไปใน host
Profile / presetชุดบทบาทสำหรับงานประเภทหนึ่ง ไม่ได้มอบสิทธิ์เพิ่มเอง
Dry runการแสดงสิ่งที่จะเกิดขึ้นโดยยังไม่เขียนหรือเปลี่ยนไฟล์
Workspaceโฟลเดอร์ .devbuddy สำหรับเก็บสถานะงานและความรู้ของโครงการ

เลือกเส้นทางที่เหมาะกับคุณ

ถ้าคุณต้องการ…เริ่มที่ไหน
ถาม AI ให้ช่วยวางแผนงานเล็ก ๆติดตั้ง host แล้วใช้ prompt ตัวอย่างในหน้าเริ่มต้น
สร้างหรือปรับระบบเว็บ / แอปใช้ preset product-delivery
ดูแล deploy, cloud หรือระบบล่มใช้ preset cloud-operations
วิเคราะห์ข้อมูลหรือประเมินโมเดล AIใช้ preset data-ai
ทำคู่มือหรือช่วยตอบผู้ใช้ใช้ preset support-knowledge

คุณไม่จำเป็นต้องเลือก role เองในงานแรก: ส่งเป้าหมายให้ DevBuddy แล้วให้มันเสนอทีมที่เหมาะสมก่อน การบังคับ role เป็นทางเลือกสำหรับผู้ใช้ขั้นสูง

กติกาง่าย ๆ ที่ช่วยให้ปลอดภัย

  • อย่าวางรหัสผ่าน, API key, ข้อมูลบัตร หรือข้อมูลลูกค้าใน prompt หรือไฟล์คู่มือ
  • อย่าอนุมัติคำสั่งที่คุณไม่เข้าใจ ให้ขอคำอธิบายเป็นภาษาง่ายและ dry run ก่อน
  • ใช้ repository สำเนาหรือ branch ทดสอบสำหรับการลองครั้งแรก
  • สำหรับ database และ production ให้ใช้สิทธิ์ต่ำที่สุด และอนุมัติเป็นรายการเฉพาะครั้ง

ไปต่ออย่างไร

เริ่มที่ เริ่มต้นใช้งานทีละขั้น ก่อน หากติดตั้งแล้วแต่ไม่เห็น DevBuddy ให้เปิด แก้ปัญหา สำหรับงานจริงที่ต้องเก็บประวัติร่วมกัน อ่าน Workspace หลังจากทดลอง prompt แรกสำเร็จ
