Claude Code Skill adapter

สถานะ: ยังไม่ได้ implement ใน version 0.1.0 ห้ามใช้หน้านี้เป็นคำสั่งติดตั้ง adapter ที่ยังไม่มี

Prerequisites

  • มี Claude Code ที่ติดตั้งและ sign in แล้วใน environment เป้าหมาย
  • มี Node.js, network และ account ตามคู่มือติดตั้ง Claude Code ปัจจุบัน
  • การติดตั้ง update account ที่เสียเงิน หรือการใช้ model ต้องได้ user approval ก่อน
  • มี Python หาก adapter เปิดใช้ validation scripts กลาง

ตรวจสถานะจริงด้วย claude doctor ได้หลัง user อนุมัติเท่านั้น ดูคู่มือทางการ: Anthropic Claude Code setup

วิธีติดตั้งเมื่อ checklist เสร็จ

  1. ตรวจว่าทุกรายการที่ต้องทำใน devbuddy-claude/adapter-implementation-checklist.md เป็น done
  2. อ่าน SKILL.md ของ adapter เพื่อดูตำแหน่งติดตั้งและ permission mapping ที่ผ่านการตรวจแล้ว
  3. copy เฉพาะ adapter ที่เสร็จไปยัง Claude Code Skill location ที่ user อนุมัติ
  4. เปิด project, invoke Skill และรัน health check แบบ read-only ตามคู่มือ
  5. ตรวจ checklist, settings mapping, memory resolution และ manual conformance

ห้าม copy credential, connection string หรือข้อมูลส่วนบุคคลลง Claude settings/prompt

พฤติกรรมของ adapter

Claude adapter ต้องรักษา policy กลาง: คุยกับ user ภาษาไทย, handoff ภายในภาษาอังกฤษ, ห้ามเดา, Git read-only, ขออนุมัติก่อนมี cost/tool/install/external action, ต้องมี Knowledge Impact Approval และ checklist evidence

แก้ปัญหา

  • หากไม่มี Claude Code ให้ถาม user ว่าจะติดตั้งหรือใช้ platform ที่อนุมัติอื่น
  • หาก permission/tool/model ต่างจาก policy กลาง ให้ mark checklist ว่ายังไม่เสร็จและใส่ remark
  • ห้ามใช้ permission-bypass เพื่อข้าม approval ของ DevBuddy
