Host guide

ใช้ DevBuddy กับ OpenCode

ติดตั้ง adapter หนึ่งครั้ง แล้ว materialize เฉพาะ agent preset ที่ต้องใช้ในแต่ละ project

ก่อนติดตั้ง

ต้องมี OpenCode ที่ใช้งานได้, Terminal และ approved release tag หรือ full commit SHA จากผู้ดูแล แทน <approved-ref> ด้านล่าง อย่าใช้ branch ที่เปลี่ยนได้กับงานจริง

ติดตั้ง adapter

OpenCode 
opencode plugin 'github:jennarinmeethong/devbuddy-skill#<approved-ref>::path:plugin/devbuddy-core/opencode' --global

ใช้ --global เมื่อต้องการใช้ทุก project ในเครื่อง หรือตัดออกเมื่อต้องการติดตั้งเฉพาะ project ปัจจุบัน ตัวเลือก ::path: ทำให้ติดตั้งเฉพาะ OpenCode adapter ไม่ใช่ทั้ง repository

สร้าง agent preset ให้ project

เลือก preset จาก คู่มือ Profile แล้วใช้ path ของ directory ที่ติดตั้ง OpenCode adapter เป็น <plugin-directory> คำสั่งแรกไม่เขียนไฟล์ ให้ตรวจรายชื่อก่อน แล้วจึงเติม --apply

Preview แล้ว apply 
python3 <plugin-directory>/scripts/materialize_agents.py \
  --preset product-delivery --project-root <project>

python3 <plugin-directory>/scripts/materialize_agents.py \
  --preset product-delivery --project-root <project> --apply

agent files อยู่ที่ .opencode/agents/devbuddy/ และมี ID รูปแบบ devbuddy/<role> ตัว materializer จะหยุดแทนการเขียนทับไฟล์ agent เดิม

เลือก preset อย่างไร

Presetเหมาะกับ
product-deliveryสร้างหรือปรับ product
cloud-operationscloud, CI/CD และ reliability
data-aidata pipeline, analysis และ AI evaluation
support-knowledgesupport, FAQ และคู่มือ

Profile เป็น metadata สำหรับการเลือก role เท่านั้น ไม่ได้มอบ permission ใหม่ อ่านขั้นเพิ่มและถอน profile แบบละเอียดใน หน้า Profile

การใช้งานอย่างปลอดภัย

เริ่มจาก prompt ให้เสนอแผนก่อน, ตรวจ scope และ role ที่จะใช้, แล้วค่อยอนุมัติการแก้ไฟล์หรือ action ภายนอก อย่าใส่ secret ลงใน agent file หรือ prompt; database และ production ต้องมี approval เป้าหมายเฉพาะเสมอ

เมื่อมีปัญหา

หากติดตั้งแล้วไม่พบ plugin ให้ตรวจ ref และ syntax ของคำสั่ง หาก materialize บอกว่าไฟล์มีอยู่ อย่า overwrite; ตรวจ agent ที่มีอยู่หรือเลือก preset อื่น อ่าน แก้ปัญหา สำหรับ error ทั่วไป

ก่อนหน้าProfile และ presetกลับไปเริ่มต้นใช้งาน
